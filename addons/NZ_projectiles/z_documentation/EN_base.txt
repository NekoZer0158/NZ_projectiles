Everything written below works for both 2D and 3D, with some exceptions, that will be mentioned

Base:
	Projectile - base class for 2D projectiles, doesn't have module support, has ID.
	Projectile3D - base class for 3D projectiles, doesn't have module support, has ID.
	Projectile_extended - a subclass of class Projectile, has module support.
	Projectile3D_extended - a subclass of class Projectile3D, has module support.
	name_hit - the name for the function, that will be called, in a node in which the projectile entered.
	(usually it's CharacterBody2D). By default it's "hit".
	type - if type of the projectile is the same as type of, e.g. custom subclass of CharacterBody2D, then the projectile will ignore the body, but if the type is different then the projectile will hit the body.
	You can't change type through the inspector, it was done for you to make your own way to change the type. E.g. there are 3 factions in your game and they are all fighting each other, you create enum{FACTION_1,FACTION_2,FACTION_3} and use it to set type for the projectile through custom classes or just scripts.
	Changing type through the inspector wouldn't be comfortable, because it's hard to understand what certain type means if it's a number, e.g. 0 - faction red, 1 - faction blue and 2- faction green.
	The plugin doesn't contain tools to spawn projectiles, because they are in a different plugin - NZ_projectiles_emitter

Modules:
	Module - name for the resources, used by Projectile_extended and Projectile3D_extended.
	Atk_change_projectile - base for changing projectile damage.
	Speed_change_projectile - base for changing projectile speed.
	Move_extended_projectile - base for changing projectile movement (ONLY 2D).
	Move_extended_projectile3D - base for changing projectile movement (ONLY 3D).
	Hit_extended_projectile - base for changing arguments for the "hit" function.
	Remove_projectile - base for changing consequences for projectile when body enters it.

In the folder "NZ_projectiles/Scenes", you can find scenes in which you can see different variants of
how you can use projectiles. In the scene "Sandbox" you can try out different stuff with projectiles.
I recommend checking scripts, where you can find information about some variables and functions.

If the inspector doesn't allow you to change values in modules in the inspector, just save the project
close the resource and open it again in the inspector
