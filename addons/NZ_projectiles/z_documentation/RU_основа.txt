Всё ниже описанное подходит как для 2D, так и для 3D проджектайлов (снарядов), кроме отдельных случаев,
которые будут указаны

Основа:
	Projectile - основной класс для 2D проджектайлов, не имеет поддержки модулей, имеет ID.
	Projectile3D - основной класс для 3D проджектайлов, не имеет поддержки модулей, имеет ID.
	Projectile_extended - подкласс класса Projectile, добавляет возможность ставить модули.
	Projectile3D_extended - подкласс класса Projectile3D, добавляет возможность ставить модули.
	name_hit - название вызываемой функции в узле, которого коснулся проджейктайл
	(в основном это CharacterBody2D). По умолчанию называется "hit".
	type - если тип снаряда и тип, например, подкласса CharacterBody2D совпадают, то столкновения не произойдёт, а если разный то снаряд ударит тело.
	Изменить type можно только через код, это сделано из-за того, чтобы вы сами смогли сделать удобный для вас выбор type. Например, в вашей игре 3 фракции и все они враждуют друг с другом, вы создаёте enum{FACTION_RED, FACTION_BLUE, FACTION_GREEN} и используете эти константы для указания type снаряда через собственные классы или просто скрипты.
	Изменение type через инспектор было бы неудобным, т.к. через числа сложнее понять к кому/чему относится снаряд, например, 0 - это фракция красных, 1 - фракция синих, а 2 - фракция зелёных.
	Плагин не содержит инструментов для вызова проджектайлов, ведь они выделены в отдельный плагин - NZ_projectiles_emitter

Модули:
	Модуль - название для ресурсов, которые может использовать Projectile_extended and Projectile3D_extended.
	Atk_change_projectile - основа для изменения атаки проджектайла.
	Speed_change_projectile - основа для изменения скорости проджектайла.
	Move_extended_projectile - основа для изменения передвижения проджектайла (ТОЛЬКО 2D).
	Move_extended_projectile3D - основа для изменения передвижения проджектайла (ТОЛЬКО 3D).
	Hit_extended_projectile - основа для изменения аргументов, передаваемых в функцию 
	с названием hit.
	Remove_projectile - основа для изменения последствий сталкивания с узлом для проджектайла.

В папке "NZ_projectiles/Scenes" вы найдёте сцены, в которых сможете посмотреть различные варианты
использования проджектайлов. В сцене "Sandbox" вы можете поэксперементировать с проджектайлами (2D).
Рекомендую посмотреть скрипты, ведь в них указана информация о некоторых переменных и функциях.

Если вы не можете изменить значения переменных в модулях в инспекторе, сохраните проект, а затем закройте
и откройте ресурс в инспекторе
